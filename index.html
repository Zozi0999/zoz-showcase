// How It Works

ONE PLACE FOR CLOUD AI AND YOUR TERMINAL

Free models for everyday tasks, paid models when you need something stronger, and your own computer's terminal, all in the same window.

TWO TIERS OF CLOUD AI

ZOZ ROUTER is a personal project by Zozi Atul Azimi. He wanted one place to use free and paid AI models side by side, and to control his own computer from the same screen.

🦙 Ollama Cloud (free): Open models hosted in the cloud. They cost nothing and don't use your laptop's CPU or GPU.

⚡ OpenRouter (paid credits): Hundreds of models, including the big commercial ones. You only pay for what you use, so it's there when a task needs more reasoning power.

💻 Terminal and remote access: A full Windows terminal inside the browser. Through a Cloudflare tunnel you can open it from your phone, protected by a 6-digit PIN.

// Features

WHAT IT CAN DO

The main parts of ZOZ ROUTER and what each one is for.

Built-in Terminal

A real Windows terminal (ConPTY through node-pty) streamed to the browser over SSE. It supports multiple tabs and a split view where the pane under your mouse gets focus automatically, so you don't have to click back and forth. Your sessions stay intact when you switch tabs.

ConPTY • SSE • xterm.js

Remote Access with Cloudflare

Use your laptop at home from your phone, wherever you are. ZOZ ROUTER starts cloudflared for you, locks the session with a 6-digit PIN, and pairs your phone when you scan a QR code. On mobile you also get a touch keybar (with vibration feedback) for keys like Ctrl, Tab and the arrows.

Phone to PC • PIN lock

BioEndocrine Self-Check v2

A background checker that keeps the interface working. It runs 405 checks on the page, catches model API errors, cleans up garbled text (mojibake) and leaked tags, stops the layout from spilling off the screen, and fixes buttons that end up hidden behind other elements.

5 check areas • Auto-fix

Canvas

A scratchpad for trying out HTML, CSS, SVG, Mermaid diagrams and small JavaScript widgets. The code runs in a sandbox and the preview updates right away. You can keep several scratch files open in tabs.

Live preview • Sandbox

Deep Research (Custom URLs)

A research agent that searches several sources, reads the pages you point it to, collects citations, and writes everything up as a Markdown report.

Multiple sources • Citations

Auto Enter for AI CLIs

Spots confirmation prompts from AI coding tools like Claude Code, Gemini CLI and Antigravity CLI (for example [Y/n], Accept file edit? or Allow creation?) and answers them for you, so long jobs don't stall waiting for a keypress.

Auto Enter • Hands-free

// Setup & Deployment

HOW TO INSTALL & RUN

Clone the repository, install the dependencies, and start the server. It only takes a few minutes.

1

CLONE REPOSITORY FROM GITHUB

Visit Repo

Open a terminal or Command Prompt and run git clone to download the source code:

# Download the repository
git clone https://github.com/Zozi0999/zoz_router.git
cd zoz_router
2

INSTALL DEPENDENCIES

ZOZ ROUTER runs on Node.js. Run npm install to install its dependencies, including node-pty, which powers the terminal:

# Installs node-pty (Windows terminal support)
npm install
3

LAUNCH THE APPLICATION

Start ZOZ ROUTER with the batch file, or run it with Node.js yourself:

Option A (recommended): Double-click start.bat in the project folder:

# Windows launcher
start.bat

Option B (manual): Start the server from the terminal:

# Start the server with Node.js
node server.js
4

OPEN THE DASHBOARD

Open this address in your browser:

http://localhost:4040

To use it from your phone, click "🌐 Cloudflare WAN Tunnel" in the top-right toolbar, set a 6-digit PIN, and scan the QR code with your phone's camera.

Learning on His Own

While a lot of people his age spend their free time gaming, Zozi spent late nights reading about systems programming, pseudo-consoles and network streams. With just an ordinary laptop, he learned by reading open-source code and technical documentation.

Built Out of Need: Checking His Laptop from School

The remote access feature came from a real problem. Zozi wanted to keep an eye on long builds and AI jobs running on his laptop at home while he was at school. So he added a Cloudflare tunnel, a 6-digit PIN, and QR-code pairing for his phone.

Working Directly with Windows ConPTY

Instead of making yet another simple web wrapper, he connected straight to Windows ConPTY through node-pty and streamed it to the browser with Server-Sent Events. The split terminal, where focus follows your mouse and the active pane is outlined, is all his own work.

Free and Paid AI, Side by Side

He didn't want to be stuck paying for one expensive subscription. So ZOZ ROUTER uses Ollama Cloud for free open models, and OpenRouter with pay-as-you-go credits when a task needs a stronger model.
