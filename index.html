// Setup & Deployment

HOW TO INSTALL & RUN

Follow these straightforward steps to clone the official GitHub repository and launch ZOZ ROUTER on your computer.

1

CLONE REPOSITORY FROM GITHUB

Visit Repo

Open your terminal or Command Prompt, then run git clone to download the complete source code from the official GitHub repository:

# Clone official repository by Zozi Atul Azimi
git clone https://github.com/Zozi0999/zoz_router.git
cd zoz_router
2

INSTALL DEPENDENCIES

ZOZ ROUTER is architected on top of lightweight Node.js native primitives. Execute npm install to install the required node-pty terminal engine:

# Install node-pty ConPTY virtual console engine
npm install
3

LAUNCH THE APPLICATION

You can launch ZOZ ROUTER via the automated 1-click batch launcher or directly with Node.js:

Option A (Recommended 1-Click): Double-click start.bat in the project directory:

# 1-Click Windows execution bypass launcher
start.bat

Option B (Manual CLI): Run server daemon directly:

# Direct Node.js daemon start
node server.js
4

ACCESS COCKPIT & WAN REMOTE

Open your browser and navigate to the local portal:

http://localhost:4040

To access your terminal from your smartphone while traveling, click "🌐 Cloudflare WAN Tunnel" in the top-right toolbar, enter your 6-digit PIN, and scan the pairing QR code directly with your phone camera!
