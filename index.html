TWO TIERS OF CLOUD AI

ZOZ ROUTER is a personal project by Zozi Atul Azimi. He wanted one place to use free and paid AI models side by side, and to control his own computer from the same screen.

🦙 Ollama Cloud (free): Open models hosted in the cloud. They cost nothing and don't use your computer's CPU or GPU.

⚡ OpenRouter (paid credits): Hundreds of models, including the big commercial ones. You only pay for what you use, so they're available whenever a task needs more reasoning power.

💻 Terminal and remote access: A full Windows terminal inside the browser. You can open it from your phone through a Cloudflare tunnel, protected by a 6-digit PIN.

// Features

WHAT IT CAN DO

The main parts of ZOZ ROUTER and what each one is for.

Built-in Terminal

A real Windows terminal (ConPTY through node-pty) streamed to the browser over SSE. It supports multiple tabs and a split view where the pane under your mouse gets focus automatically, so you don't have to click back and forth. Your sessions stay intact when you switch tabs.

ConPTY • SSE • xterm.js

Remote Access with Cloudflare

Use your laptop at home from your phone, wherever you are. ZOZ ROUTER starts cloudflared for you, locks the session with a 6-digit PIN, and pairs your phone when you scan a QR code. On mobile you also get a touch keybar (with vibration feedback) for keys like Ctrl, Tab and the arrows.

Phone to PC • PIN lock

BioEndocrine Self-Check v2

A background checker that keeps the interface working. It runs 405 checks on the page, catches model API errors, cleans up garbled text (mojibake) and leaked tags, stops the layout from spilling off the screen, and fixes buttons that end up hidden behind other elements.

5 check areas • Auto-fix

Auto Enter for AI CLIs

Spots confirmation prompts from AI coding tools like Claude Code, Gemini CLI and Antigravity CLI (for example [Y/n], Accept file edit? or Allow creation?) and answers them for you, so long jobs don't stall waiting for a keypress.

Auto Enter • Hands-free

// Setup & Deployment

HOW TO INSTALL & RUN

Clone the repository, install the dependencies, and start the server. It only takes a few minutes.

1

CLONE REPOSITORY FROM GITHUB

Visit Repo

Open a terminal or Command Prompt and run git clone to download the source code:

# Download the repository
git clone https://github.com/Zozi0999/zoz_router.git
cd zoz_router
2

INSTALL DEPENDENCIES

ZOZ ROUTER runs on Node.js. Run npm install to install its dependencies, including node-pty, which powers the terminal:

# Installs node-pty (Windows terminal support)
npm install
3

LAUNCH THE APPLICATION

Start ZOZ ROUTER with the batch file, or run it with Node.js yourself:

Option A (recommended): Double-click start.bat in the project folder:

# Windows launcher
start.bat

Option B (manual): Start the server from the terminal:

# Start the server with Node.js
node server.js
4

OPEN THE DASHBOARD

Open this address in your browser:

http://localhost:4040

To use it from your phone, click "🌐 Cloudflare WAN Tunnel" in the top-right toolbar, set a 6-digit PIN, and scan the QR code with your phone's camera.

TEARS AT THE FOOT OF MT. RINJANI: FROM A HUMBLE QUR'AN SHELTER WITHOUT KINDERGARTEN TO THE GLOBAL AI STAGE

The unvarnished, heart-wrenching story of Kampung Sempol (Dusun Sempol) in remote East Lombok—and how Zozi Atul Azimi rose from freezing nights at a humble prayer-reading shelter and the fragile benches of SD Islam Sempol ("House of Hope").

1.5 km Steep Rocky Trail Qur'an Shelter → PAUD KB Jibalul Ulum SD Islam Sempol (NPSN: 69990901) 57 Global Certifications & ZOZ ROUTER

Along the quiet slopes of Mount Rinjani, far removed from tourist spotlights, lies a remote hamlet that progress once seemed to forget: Kampung Sempol (Dusun Durian Utara, Desa Perigi, Kecamatan Suela, East Lombok, NTB). Reaching it from the village hall means enduring 1.5 kilometers of steep, jagged rocks and gravel—a punishing trail that turns into a treacherous river of mud whenever mountain rains descend, isolating nearly a hundred households where nine out of ten parents are forced to leave as migrant laborers just so their children can eat.

During Zozi Atul Azimi's early childhood, the words "PAUD" or "TK" (kindergarten) did not even exist in Sempol. There were no painted playgrounds, no preschool uniforms, and no colorful picture books. Instead, when twilight fell and Rinjani's biting mountain mist froze tiny fingertips, little Zozi walked in thin sandals or barefoot to a humble local Qur'an study shelter (tempat mengaji)—clinging to worn pages of Iqro' under a trembling dim bulb, whispering Arabic letters into the dark while crickets and cold wind answered outside.

From that modest Qur'an shelter, he stepped into the freezing morning fog toward SD Islam Sempol (NPSN: 69990901)—a fragile pioneer satellite school known as "Rumah Harapan" (House of Hope) long before major charitable donations arrived in 2025. Back then, the classroom shook against mountain gales, torrential rain roared over tin roofs until teachers' voices vanished completely, and there was not even a proper toilet. Yet while hunger gnawed at his stomach and sharp stones bruised his feet along that 1.5 km path, Zozi quietly wiped away tears over tattered notebooks and refused to surrender.

"Years later, after relentless advocacy brought major donations to rebuild SD Islam Sempol, that very Qur'an shelter where little Zozi once shivered grew into PAUD KB Jibalul Ulum—the official early-childhood school and Qur'an foundation for Sempol's new generation. Zozi never wore a kindergarten uniform because no PAUD existed in his time, yet every drop of sweat and every trembling letter he recited on those cold floors forged an unbreakable soul."

Alone through sleepless highland nights, turning isolation into iron resolve, the boy who started in an unnamed Qur'an shelter and a pioneer school without sanitation taught himself systems engineering word by word—earning 57 official global certifications from IBM, Anthropic, Google Cloud, Cognitive Class, UNESCO, HP LIFE, Saylor University, Dicoding Academy, and Coursera, building ZOZ ROUTER, and launching dusun-sempol-news.zozdocs.com so the tears and triumph of Kampung Sempol will never be forgotten by the world.
