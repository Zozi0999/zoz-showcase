// Setup & Deployment

HOW TO INSTALL & RUN

Follow these straightforward steps to clone the official GitHub repository and launch ZOZ ROUTER on your computer.

1

CLONE REPOSITORY FROM GITHUB

Visit Repo

Open your terminal or Command Prompt, then run git clone to download the complete source code from the official GitHub repository:

# Clone official repository by Zozi Atul Azimi
git clone https://github.com/Zozi0999/zoz_router.git
cd zoz_router
2

INSTALL DEPENDENCIES

ZOZ ROUTER is architected on top of lightweight Node.js native primitives. Execute npm install to install the required node-pty terminal engine:

# Install node-pty ConPTY virtual console engine
npm install
3

LAUNCH THE APPLICATION

You can launch ZOZ ROUTER via the automated 1-click batch launcher or directly with Node.js:

Option A (Recommended 1-Click): Double-click start.bat in the project directory:

# 1-Click Windows execution bypass launcher
start.bat

Option B (Manual CLI): Run server daemon directly:

# Direct Node.js daemon start
node server.js
4

ACCESS COCKPIT & WAN REMOTE

Open your browser and navigate to the local portal:

http://localhost:4040

To access your terminal from your smartphone while traveling, click "🌐 Cloudflare WAN Tunnel" in the top-right toolbar, enter your 6-digit PIN, and scan the pairing QR code directly with your phone camera!

// The Journey & Engineering Philosophy

THE STORY: FROM AN INDONESIAN CLASSROOM TO A SOVEREIGN AI WORKSTATION

A testament to self-taught persistence, engineering curiosity, and the relentless pursuit of computing autonomy.

01

The Curious 16-Year-Old in Vocational School (SMK)

While most teenagers spend their evenings casually gaming or scrolling feeds, Zozi was captivated by operating system fundamentals, kernel consoles, and neural computation. As an active vocational high school (SMK) student in Indonesia, he spent countless late nights studying how processes communicate, how Windows handles terminal pseudo-consoles, and how modern LLMs process streaming tokens. Technical documentation and open-source code became his personal classroom.

02

Born from Real Need: Remote Tunneling from School

One of ZOZ ROUTER's most defining innovations — the zero-config Cloudflare WAN Remote Access — was born directly out of Zozi's daily student life. Sitting in his vocational school classroom with only a smartphone, he wanted to supervise heavy AI builds and long-running terminal scripts running on his laptop at home. Instead of using complex commercial VPNs, he engineered a native duplex SSE tunnel directly accessible from his phone camera via 1-click QR code pairing and 6-digit cryptographic PIN authentication.

03

Wrestling with Windows ConPTY Virtual Console APIs

Rather than settling for basic web command shells, at age 16 Zozi dove deep into Microsoft Windows Pseudo Console (ConPTY) APIs via node-pty. He engineered an integrated dual-pane split console featuring raw ANSI escape sequence rendering, bidirectional Server-Sent Events, and a frictionless Focus-Follows-Mouse (Hover-to-Focus) mechanism with active pane glowing — delivering a terminal experience comparable to top-tier commercial software.

04

Radical Local-First Digital Sovereignty

Frustrated by modern tools that lock developers into expensive subscriptions and harvest confidential code telemetry, Zozi founded ZOZ ROUTER on the principle of absolute digital sovereignty. By prioritizing offline local intelligence via Ollama, users can run private, confidential neural workflows with zero telemetry, zero fees, and complete data ownership — seamlessly falling back to OpenRouter cloud models only when deep frontier reasoning is required.

05

Biomimetic 5-Pillar Self-Healing (BioEndocrine)

Recognizing that long-running web consoles often suffer from UI decay, button obstruction, or broken token streams, Zozi created an autonomous watchdog engine inspired by the human endocrine balance. Performing continuous 405-point connectome audits, the system automatically detects and repairs viewport blowouts, tag leaks, and UI obstacles in real-time without interrupting active work.

06

Proving Excellence Has No Age Requirement

ZOZ ROUTER stands as living proof from Indonesia that deep engineering capabilities, systems architecture, and AI tooling are not reserved for corporate tech giants. With grit, a workstation laptop, and an uncompromising drive to build, a 16-year-old vocational student crafted a production-grade workstation that empowers developers to command both local and cloud intelligence with absolute sovereignty.
